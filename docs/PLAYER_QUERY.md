## 现场验证与实现（2026-09-30）

正常游戏内“查看资料”操作已采样成功，用户确认页面显示资料。请求是 **0x364F**，响应是 **0x3650**。

| 请求部分 | 线上编码 |
| --- | --- |
| 目标服务器 ID | 固定 u16，小端 |
| 目标角色数据库 ID | 固定 u64，小端 |

两项请求正文合计 10 字节，消息号 2 字节，最终明文帧 13 字节。服务器 ID 的反射 u32 是内存布局，不能当作线上宽度。`9090950` 中的 `FNetworkStaticsGame::SendViewChar` 日志字符串、消息号常量和 `92C34D0` 写入函数互相印证；`9331270` 预留四字节长度，`93312E0` 最终变长编码并调整起始位置。因此写入结束时抓到的缓冲区前四字节还不是最终帧头。

调用入口寄存器与写入后明文中的两个参数一致。发送链走 `9202660` 的现有连接队列；本次没有采集该请求对应的加密状态，未将这条明文与线上密文逐字节比对。不能把旧密文或这里的明文直接注入现有连接。

接收分发表将 `3650` 映射至 `926321C`，调用 `92C43D0`，结果为 0 时进入 `9090AF0`。本次抓包中有一条成功响应，解压后的完整帧为 4674 字节，已解析前 91 字节，保留其余 4583 字节。已解析昵称、种族、性别、等级（本次 50）、征服者等级、装备等级原值、出生/当前服务器（线上各 u16）、在线标志、称号及公会/联盟信息。装备、外观及养成数据的尾部尚未完整解析，界面明确标为未解析，不能据此声称完整资料已解码或整个响应绝无位置数据。

`8FA47A0` 在发送前检查间隔、已有请求状态和数据库 ID；`8FA4730` 检查冷却截止时间；成功和失败处理均会清除等待标志并设置后续查询间隔，具体配置数值未确认。响应已解析前缀没有目标数据库 ID，关联依据为本次单一操作、时序和服务器匹配，不能据此实现无序并发查询。

工具支持还原后出站 `364F` 的完整解析，以及入站 `3650` 基础字段的部分解析。新增独立的“玩家资料查询”页，以透明代理方式发起单个角色查询。附近玩家出现消息 `3645` 已提供数据库 ID，并可选提供服务器 ID；若缺服务器信息，不能自行猜测目标服务器。

证据：`artifacts/field-analysis/view-char-native-code.json`、`verify-view-char.py` 和 `artifacts/view-char-live-20260930-004006/` 下的抓包、调试采样、响应帧与 verification.json。现场结束后已验证游戏 RUNNING 且无遗留断点。抓包、角色资料和会话证据不随发布包分发。

## 独立透明代理（2026-09-30）

运行时不依赖 x64dbg、IDA、`.a2cs` 或游戏进程内存。不会注入 DLL。WinDivert 将新建的目标 IPv4 TCP 连接转到本地代理，代理通过另一条 Windows TCP 连接与原服务器通信；两条连接各自处理序号、ACK、重传与窗口。程序只查询进程名和连接归属。

1. 以管理员身份打开工具，进入“玩家资料查询”，世界服务端口默认 `13328`。
2. 在游戏连接建立前点击“启用透明代理”，再登录游戏。已存在的连接不接管。
3. 状态依次显示等待握手、接管公钥、握手完成、出站编码验证。至少三条已支持的出站消息解析通过后，才能查询。
4. 在周围对象详情点击“填入玩家资料查询”，或输入服务器 ID 和角色数据库 ID，选择对应的代理连接，点击“查询一次”。没有目标服务器 ID 时不发送。
5. 最小发送间隔五秒、每连接一个待处理请求。十五秒无响应后停止该连接的后续查询，不自动重发。这个间隔是本工具设置，不是已确认的服务器限速值。
6. 查询结果显示在独立页面。正常串行情况下，工具自己请求的 `3650` 响应只交给工具；若响应在 LZ4 容器中，保留容器内其他消息。游戏同时发起查询时标记关联不明，保留游戏收到的消息，并禁止后续工具查询。
7. “停止接管新连接”保留已有转发。关闭游戏连接后才能关闭代理或正常退出；进程被强制结束或转发失败会断开已接管的连接。

实时功能现已统一到独立代理。启用代理后，收发消息、周围对象、自身移动和资料查询自动使用同一消息来源，不需要再开始旁路捕获。`.a2session` 保存明文、方向与连接信息，可以无密钥回放；历史 PCAP 的 `.a2cs` 兼容入口仅用于旧数据。详见 UNIFIED_PROXY.md。

### 自动握手依据

- `9203320 → 9211EB0` 创建每连接握手对象，虚表 `DEF48E8`。
- `932BE70` 生成 RSA-2048 密钥，客户端公钥指数为 3；`B9357B0` 的 ASN.1 描述为 `RSAPublicKey`，成员只有 `n/e`，即 PKCS#1 DER。
- `90DB120 → 932C080 → 92B8190` 把公钥装入明文 `3610`：消息号后为 ULEB 长度、公钥和版本/平台/语言/字符串/标志尾部。
- `3611` 由 `92B8630` 读取：结果 u16、原始字段 u32、ULEB 长度、密文及三个 u32 尾部。`90DB54B` 调用握手虚表 `+0x20 → 932C040 → B92B100`，对应 RSA 私钥解密，padding=4（OAEP，SHA-1 默认值）。
- 解开的字节交给 `9204620 → 9211F30 → 932C140`：标准 RC4 KSA，随后 PRGA 的索引初始值为 `i=1,j=0`，不加密帧长前缀。`92020F0` 中两个状态用于发送前加密、发送后恢复缓冲区，不是上下行各一个。
- 代理用 Windows CNG 生成自己的 RSA-2048 密钥（指数 65537），替换 `3610` 公钥并重新计算消息长度。`3611` 解开后，将同一会话密钥用原客户端公钥重新加密。握手尾部保持原字节。私钥和会话密钥不写日志或文件，连接结束释放。
- 插入查询后，分别维护客户端解密状态与服务器加密状态，后续客户端正文先解密再加密。服务器入站消息按已观察到的明文帧处理；不是通用 TLS 代理。

证据：`artifacts/field-analysis/transparent-handshake-static.json`、`handshake-wire-evidence.json`。已有抓包含 285 字节的 `3610`（268 字节 RSA 公钥）和 280 字节的 `3611`（256 字节 RSA 密文）。

### 验证范围与限制

本地端到端测试使用真实 WinDivert 和 TCP 套接字，Python 模拟游戏/服务器独立使用 OpenSSL RSA-OAEP-SHA1 与标准 ARC4：指数 3 的客户端和指数 65537 的代理互通；无需导入状态，自动发出 `364F`；后续消息仍可正确解密；LZ4 内工具响应被隔离，其他通知保留；双向半关闭成功。运行 `scripts/test_query_proxy.py`，结果见 `artifacts/field-analysis/independent-proxy-integration.json`。测试只连接本机回环地址。

**真实连接验证：用户提供的运行截图已显示“握手与出站编码已自动验证，可以查询”，随后完成主动查询并反馈“资料已显示，游戏正常”。** 真实服务器接受替换公钥、会话密钥重封装及至少三条出站结构校验已有截图与日志证据；真实主动查询、资料显示及游戏保持正常由用户现场确认。该证据只适用于本次连接和客户端版本，不表示其他版本均兼容，也不代表装备及养成尾部已经完整解析。

遇到未知首帧保持原样转发，已替换握手后发生密钥/边界错误则断开连接，防止输出错误编码。当前只接管指定端口的 IPv4 TCP，一次启用最多保留 32 条连接记录，关闭代理后可重新启用。IPv6、加速器外层加密隧道和其他版本握手未验证。

装备/养成尾部、离线玩家、跨服目标及服务器频率限制仍未完整解析或实测。

## 2026-10-01 失败返回码显示

玩家资料查询页直接显示十进制/十六进制返回码及已确认的 EResult 名称；查询服务页的最近失败显示相同解释。机器通信仍保留 `game_query_failed:<数字>`，不改变现有调度器约定。未知码不推断含义，超时不伪造服务器返回码。非零响应不展示附带的默认时装为有效资料。

当前转储 EResult 表 `0x14DD41BE0..0x14DD41C50`：6432 Character_NotExist、6433 Character_InvalidName、6434 Character_Blocked、6435 Character_RequetCharacterViewTooSoon、6436 Character_Dummy、6437 Character_InvalidServerId、6438 Character_MaxAscensionGrade、6439 Character_InvalidRace。Blocked/Dummy 的具体业务触发条件尚未确认；TooSoon 未确认要求等待的秒数；InvalidServerId 不能单独证明一定是跨大区。

诊断 `query_result` 记录连接、返回码、基础字段是否完整、请求是否重叠和目标区服/角色数据库 ID。即使后续字段截断，完整读到的非零返回码仍可展示；缺少结果字节则保持未知。
