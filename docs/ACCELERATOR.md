# 虚拟网卡加速模式

Aion2Pipe 统一支持使用虚拟网卡、TUN、Wintun、WireGuard 或同类系统路由模式的加速器，不再包含任何品牌或进程专用适配。

## 数据路径

- 登录与世界协议：`AION2.exe → Aion2Pipe → Windows 当前路由 → 加速器虚拟网卡 → 游戏服务器`
- 聊天协议：`AION2.exe:443 → Aion2Pipe → 127.0.0.1:18080 → 聊天解析组件 → Windows 当前路由 → PlayNC`

Aion2Pipe 不检查加速器进程名，不扫描动态监听端口，不伪装游戏来源端口，也不接管加速器外层隧道。

## 使用顺序

1. 在加速器中开启虚拟网卡/TUN 模式并开始加速。
2. 以管理员身份启动 Aion2Pipe。
3. 启动游戏并建立全新连接。

切换加速器或线路后应完全退出并重新启动游戏。界面应显示“虚拟网卡/系统路由模式”。
